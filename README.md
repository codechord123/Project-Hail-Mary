# 🚀 헤일메리 분수 미션 (Hail Mary: Fraction Mission)

초등학교 5학년 분수의 덧셈·뺄셈 단원 학습용 웹 게임.

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 기술 스택

React 18 · Vite · TypeScript · Tailwind CSS · Zustand · React Router · KaTeX · Framer Motion

## 진행 상태

- [x] Phase 1 MVP — 챕터 1 (분모 같은 분수의 덧셈)
- [ ] Phase 2 — 챕터 2~5
- [ ] Phase 3 — 챕터 6~7, 컷신, 시각화
- [ ] Phase 4 — 학급 시범 적용
